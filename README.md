# React SPA CRUD Application

A Single Page Application (SPA) built with React, Hooks, and React Router that interfaces with a mock REST API via Axios.

## Features
- **Create**: Add new posts via form.
- **Read**: Fetch and view all posts with loading states.
- **Update**: Edit existing posts seamlessly.
- **Delete**: Remove posts with safety confirmations.

## How to Run Locally

### 1. Start the Backend API
```bash
cd backend
npm install
npm start

### 2. start the frontend
cd  frontend
npm install
